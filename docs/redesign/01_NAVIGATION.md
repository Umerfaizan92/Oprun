## Route and permission migration

- All canonical `b01`–`b09` page hashes, bare legacy page names, original aliases and bare old group links still resolve with the same permission evaluation. `#b06` opens SEO Command Centre; `#b09` opens billing even though their groups are combined.
- `More tools` is progressive disclosure, not authorization. Deep links automatically expand the selected retained tool. Finder/manual share the same 60-item definitions. All 60 remain reachable by keyboard.
- Context links are filtered from the existing allowed page sequence. Unsaved-change protection runs before a context route change. Original form nodes and section/history handlers stay attached.
- Founder routes, identity and grants remain independent. No subscriber role grants operator access. Public Operator sign-in stays visible; Business sign-in has no Install control.
- Test fixtures retain every old path and alias, test denied feature scopes and cross-business channel access, and CI exercises all 60 Business and 34 Founder pages on phone and desktop.
- No database migration or production-data mutation is part of the redesign. Future record consolidation must be additive, idempotent, tenant-scoped, reconciled against source totals and reversible.
