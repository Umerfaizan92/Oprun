## Before this change (same machine, 24 Nov 2026)

Workspace pages scored 26–35 (LCP 8.9–10.0 s, TBT 2.2–3.8 s, about 990 KB in 179–183 requests: 49 stylesheets and 86
scripts). Joining them into bundles (`src/asset-bundles.js`) cut that to about 640 KB in 56 requests with one
stylesheet, and the scores rose to 35–48. The Operator Console went from 85 to 100.

## What is left for the workspace (not done yet)

The remaining time is the browser running the code of every workspace page at start-up, although only one page is
shown (about 1.5–2.5 s of blocking work on the simulated phone). Reaching 85 needs the pages' code to load when a page
is first opened instead of all at once (load-on-open per page, with the Command Centre and navigation loaded first).
That touches how each of the ~55 page modules registers itself, so it is planned as its own change with the visual,
navigation and UI suites as the safety net.
